# cenjhihli.github.io

Personal academic website of Cen-Jhih Li. Plain HTML/CSS, no build step.

- `index.html`: all page content
- `style.css`: styles (light and dark mode)
- `Cen_Jhih_Li_CV.pdf`: CV linked from the page
- `.nojekyll`: tells GitHub Pages to serve files as-is

## Updating

- **News**: add a new `<li>` at the top of the `news` list in `index.html`.
- **Publications**: copy an existing `<li>` in the `pubs` list and edit it.
- **Photo**: overwrite `profile.jpg` (4:5 portrait, about 500×625 px).
- **CV**: overwrite `Cen_Jhih_Li_CV.pdf` with the new version.

Commit and push; GitHub Pages republishes within a minute or two.
